C.2 Implementar Grad-CAM simplificado para explicabilidad 12 pts
CódigoDiagnóstico
🔍 Contexto El hospital de la Sección A exige que el modelo sea explicable: los radiólogos deben ver qué región de la radiografía activó la predicción. Grad-CAM (Gradient-weighted Class Activation Mapping) es la técnica estándar para esto en CNNs. A continuación se provee el esqueleto de una implementación simplificada con TensorFlow/Keras.
import tensorflow as tf import numpy as np import matplotlib.pyplot as plt def compute_gradcam(model, img_array, class_idx, last_conv_layer_name): """ Calcula el mapa de activación Grad-CAM para una imagen. Args: model : modelo Keras entrenado img_array : array (1, H, W, C) preprocesado class_idx : índice de la clase objetivo (int) last_conv_layer_name : nombre de la última capa convolucional (str) Returns: heatmap : array 2D normalizado [0,1] del tamaño de la última conv map """ # Paso 1: Crear submodelo que devuelva activaciones + predicción final grad_model = tf.keras.models.Model( inputs=model.input, outputs=[ model.get_layer(last_conv_layer_name).output, # activaciones conv model.output # logits finales ] ) # Paso 2: Forward pass dentro de GradientTape with tf.GradientTape() as tape: conv_outputs, predictions = ___ # ← Completa: llama a grad_model loss = predictions[:, ___] # ← Completa: selecciona la clase correcta # Paso 3: Gradientes de la pérdida respecto a las activaciones conv grads = tape.gradient(loss, ___) # ← Completa: ¿gradiente respecto a qué? # Paso 4: Pooling global de los gradientes (importancia por canal) pooled_grads = tf.reduce_mean(grads, axis=___) # ← Completa: ¿qué ejes? # Paso 5: Ponderar canales de la última activación conv conv_outputs = conv_outputs[0] # quitar dimensión batch heatmap = conv_outputs @ pooled_grads[..., tf.newaxis] heatmap = tf.squeeze(heatmap) # Paso 6: ReLU y normalización heatmap = tf.maximum(heatmap, 0) / (tf.math.reduce_max(heatmap) + 1e-8) return heatmap.numpy() def overlay_heatmap(heatmap, original_img, alpha=0.4): """Superpone el heatmap sobre la imagen original.""" import cv2 heatmap_resized = cv2.resize(heatmap, (original_img.shape[1], original_img.shape[0])) heatmap_color = cv2.applyColorMap( np.uint8(255 * heatmap_resized), cv2.COLORMAP_JET ) return cv2.addWeighted(original_img, 1-alpha, heatmap_color, alpha, 0)
